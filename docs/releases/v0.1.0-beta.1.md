# v0.1.0-beta.1

First reviewable beta candidate for the Oxlint-native successor to
`eslint-config-setup`.

## Stable surfaces

- eight prebuilt standard configurations selected by React, Node.js, and AI options;
- complete core/import/TypeScript behavior with a pinned type-aware backend;
- named syntax-only, Vitest, and Jest configurations;
- native React, JSX accessibility, and Node.js rules;
- equivalent public JSON exports for every TypeScript loader;
- 27 machine-readable ledger entries with generated documentation and fixtures;
- exact package-content, clean-consumer, provenance, and deterministic-build gates.

## Experimental surface

`getExperimentalReactCompilerOxlintConfig()` enables the native
`react/react-compiler` rule as a warning. It is isolated from all standard and
stable named configurations and may change with pinned Oxlint upgrades.

## Migration notes

This release optimizes for behavioral defect coverage rather than one-to-one
ESLint identifier mapping. Formatting, Markdown/MDX, spelling, JSON/package
metadata, and unproven JavaScript-plugin domains remain separate tools, research,
or accepted gaps.

## Known gaps

- no Testing Library, Playwright, Storybook, SonarJS, or regex JavaScript plugin;
- no automatic standalone-binary asset downloader;
- no stable React Compiler promise;
- only the documented Oxlint `1.77.0`, tsgolint `7.0.2001`, and TypeScript `7.0.2`
  trio is supported.

## Verify before publishing

```sh
pnpm install --frozen-lockfile

```
